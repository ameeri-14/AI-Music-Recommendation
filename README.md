# AI-Music-Recommendation
# A machine learning-based project designed to analyze the characteristics of music and classify songs into different mood categories such as Happy, Sad, Energetic, and Relaxed. The system will use audio features such as tempo, energy, danceability, acousticness, and valence as input for a machine learning model, such as a Random Forest classifier, to predict the mood of a song. Based on the predicted mood, the system can also recommend suitable songs or playlists to the user. The system need the user to input their mood and the system will recommend song that fits with the user mood.
